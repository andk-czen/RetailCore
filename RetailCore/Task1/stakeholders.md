# Карта стейкхолдеров

| Роль | Зона ответственности | Что уточнять |
| --- | --- | --- |
| Спонсор проекта со стороны бизнеса |  Бизнес, финансы  | цели изменений, приоритеты бизнеса, ожидаемый эффект и допустимые ограничения |
| Руководитель команды заказов и оформления | Клиенты, заказы | Как устроен ключевой процесс, где возникают исключения, ручные операции и основные операционные проблемы. Причины возвратов |
| Сотрудник команды заказов и оформления | Клиенты, заказы | Как выполняется процесс работы с заказами  |
| Технический лидер / ведущий разработчик монолитного ядра | ИТ, технические вопросы | фактическое устройство системы, технические ограничения, сложные зависимости, узкие места и накопленный технический долг |
| Руководитель клиентской поддержки | Клиенты, заказы, поддержка | Частые обращения, ручные действия и проблемы со статусами |
| Сотрудник клиентской поддержки | Клиенты, заказы, поддержка | Как выполняется обработка обращений разных типов |
| Бизнес-заказчик / директор по цифровым продажам | Продажи, заказы | Самые популярные категории товаров и портрет клиента, какие бывают всплески активности продаж и что приводит к таким всплескам |
| Руководитель подразделения маркетинга | Акции, Промо-механики, рекламные кампании | Новые акции, каналы и партнёрские сценарии  |
| Сотрудник отдела / подразделения маркетинга | Акции, Промо-механики, рекламные кампании | В чем особенности работы, с какими проблемами в системе приходится сталкиваться, как эти проблемы решаются |
| Руководитель команды логистики | Логистика, доставка | Резервирование доставки, статусы и работа с партнёрами |
| Сотрудник отдела логистики | Логистика, доставка |  В чем особенности работы, с какими проблемами в системе приходится сталкиваться, как эти проблемы решаются |
| Руководитель команды аналитики и отчётности | Создание отчетов | Источники отчётов и причины расхождения данных  |
| Сотрудник команды аналитики и отчётности |  | В чем особенности работы, с какими проблемами в системе приходится сталкиваться, как эти проблемы решаются |
| Руководитель команды инфраструктуры и эксплуатации | Нагрузка, сбои, восстановление и свободные ресурсы | Какие процессы отнимают больше всего времени и ресурсов |
| Сотрудник команды инфраструктуры и эксплуатации |  | В чем особенности работы, с какими проблемами, связанными с системой, приходится сталкиваться, как эти проблемы решаются |
| Руководитель команды платёжных интеграций | Внешние платежные системы | SLA, ограничения, гарантии, сроки интеграций, контракты |
| Сотрудник команды платёжных интеграций |  | В чем особенности работы, с какими проблемами в системе и внешних системах приходится сталкиваться, как эти проблемы решаются |
| Представители внешних партнёрских систем | взаимодействие с внешними сервисами | Какие есть установленные SLA и прочие ограничения для систем, какие проблемы возникают при их несоблюдении, как решаются |

*Сотрудник - рядовой подчиненный, выполняющий задачи в отделе /подразделении, не руководитель.
